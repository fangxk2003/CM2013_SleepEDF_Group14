# Project guides

Follow these guides in order when you are new to the project:

1. [Getting started](GETTING_STARTED.md): check your setup, run a small real-data baseline and read its outputs.
2. [Architecture](ARCHITECTURE.md): understand the three stages and find the code to edit.
3. [Development](DEVELOPMENT.md): manage the shared environment, notebooks, tests and additional experiment commands.

For saved experiments, use the [results guide](../results/README.md) and [team results log](../RESULTS.md).

[Course handouts](course/README.md) contain the original assignment, literature map, dataset card and grading rules. They include other tracks and reference recipes; the project guides above describe this team's working code.

[Smoke-test comparison](SMOKE_TEST_COMPARISON.md) preserves the historical investigation of differing notebook and package-version results.
